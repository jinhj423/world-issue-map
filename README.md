# 세계 이슈 지도

지금 세계 어디가 뜨거운지 한눈에 보는 지도입니다. 56개국 뉴스를 한국어 헤드라인으로 모아, 나라별 **이슈 지수**를 색으로 칠합니다.

- 운영비 0원: GitHub Actions가 매시간 수집하고, GitHub Pages(또는 Cloudflare Pages)가 정적 사이트로 서빙합니다.
- AI 토큰 소모 0: 분야 분류, 핵심 단어, 이슈 지수를 모두 규칙 기반으로 계산합니다.

## 폴더 구조


### (과거) GitHub Pages 단독

저장소 하나로 수집·데이터·서빙을 전부 해결하고, 배포 횟수 제한이 없어서(공개 저장소는 Actions 무료·무제한) 30분마다 데이터를 커밋해도 비용이 0원입니다. Cloudflare Pages는 무료 플랜의 월 500회 빌드 제한에 30분 주기 커밋(월 ~1,440회)이 걸려서 제외했습니다.

1. GitHub에 **공개** 저장소를 만들고 이 폴더 전체를 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 설정합니다.
3. **Actions** 탭에서 '뉴스 수집 (30분마다)'을 열고 **Run workflow**를 눌러 첫 수집을 실행합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`에서 확인합니다. 국가 링크는 `.../#JP` 형식입니다.
5. 애드센스 등 수익화를 시작할 때 커스텀 도메인(연 1~2만 원)을 사서 Pages에 연결합니다. `<아이디>.github.io` 서브도메인으로는 애드센스 승인이 사실상 불가능하므로 도메인이 필요합니다.

로컬 확인: `python -m http.server`를 실행한 뒤 `http://localhost:8000`에 접속합니다. `file://`로 열면 fetch가 막힙니다.
파싱만 확인: `python scripts/fetch_news.py --dry`

## 뉴스 갱신 — 결정: 30분 주기, 토큰 0, 2개 이상 교차 확인

- **주기**: GitHub Actions가 매시 7분·37분에 수집합니다(예약 작업은 수 분 지연될 수 있음). 구글 뉴스 RSS는 기사 송고 후 수 분 안에 반영되므로, 사건 발생 → 사이트 표시까지 보통 30분 안쪽입니다.
- **토큰 0**: 분류·키워드·군집·지수 전부 규칙 기반(파이썬 표준 라이브러리)입니다. 수집·갱신 어디에도 AI 호출이 없습니다.
- **정확도(교차 확인)**: 나라의 대표 헤드라인 자리에는 ① 구글 뉴스가 관련 기사 2건 이상으로 묶은 사건 또는 ② 서로 다른 언론사 2곳 이상이 보도해 우리 군집에서 합쳐진 사건이 우선 배치됩니다. 단독 보도는 상세 목록에는 남지만 대표 자리는 교차 확인된 사건에 밀립니다. 언론사 2곳 이상이면 기사에 "언론 N곳" 표시가 붙습니다.
- **오보·정정**: 본문은 저장하지 않고 제목과 원문 링크만 보여줍니다. 매번 전체를 다시 계산하므로 언론사가 제목을 정정하면 다음 주기에 자동 반영됩니다.
- **장애**: 수집 성공률이 30% 미만이면 기존 데이터를 덮어쓰지 않습니다.

## 이슈 지수

`이슈 지수 = 100 × (0.6 × 보도량 + 0.4 × 평소 대비 급증)`

- **보도량**: 나라별 헤드라인을 같은 사건끼리 묶은 뒤, 관련 기사 수 × 분야 가중치 × 최신성으로 합산합니다. 상위 3개국 평균을 기준으로 로그 정규화합니다.
  - 분야 가중치: 분쟁 1.3, 재난 1.3, 정치 1.1, 경제 1.0, 기술 0.9, 사회 0.8
- **급증**: 오늘 보도량 ÷ 최근 7일 중앙값입니다. 기록이 3일 미만이면 0.5(평소 수준)로 둡니다. 따라서 **가동 3일째부터 급증 신호가 살아납니다.**
- 지도 색은 그날 수집된 나라들 사이의 상대 위치로 칠합니다.

조정 위치: `scripts/newsmap.py`의 `CATEGORIES`(분야 단어와 가중치), `heat_score`(비율), `STOPWORDS`(키워드에서 뺄 단어)

## 데이터 출처와 주의점

- 구글 뉴스 RSS를 씁니다. 한국어판 검색(`intitle:일본 OR intitle:日`)과 현지판 1면 두 가지입니다. 헤드라인과 링크만 저장하고 본문은 저장하지 않습니다.
- 구글 뉴스 RSS는 공식 API가 아닙니다. 차단이나 형식 변경이 생길 수 있고, 상업적 이용 조건도 명확하지 않습니다. 수익화 단계에서는 공식 API로 옮기는 것이 안전합니다.
  - **네이버 검색 API(뉴스)**: 무료로 하루 25,000회까지 쓸 수 있고 한국어 기사를 제공합니다. 키는 GitHub Secrets에 넣습니다.
  - **GDELT**: 무료이고 전 세계 원문 기사를 다룹니다.
- 수집이 대부분 실패하면(30% 미만 성공) 기존 `news.json`을 덮어쓰지 않습니다.
- 한자 약칭 오탐을 막기 위해 제외어를 둡니다. 예: `中企`, `中東`은 중국 기사로 세지 않습니다. 새 오탐이 보이면 `config/countries.json`의 `exclude`에 추가하면 됩니다.

## 로드맵

**1단계 — 가동 안정 (배포 직후 ~1주)**
- 실수집 3일 관찰: 빈 나라 없는지, 오탐(中企 등) 새로 생기는지, '평소 대비' 지표가 3일째부터 살아나는지

- OG 공유 이미지 1장, Google Search Console 등록

**2단계 — SEO 유입**
- 나라별 정적 페이지(`/jp/` 등 56개) Actions에서 자동 생성 — "오늘 일본 뉴스" 검색 유입용
- sitemap.xml 자동 생성, 소개·개인정보처리방침·문의 페이지(애드센스 심사 요건)

**3단계 — 기능 확장**
- 지난 7일 보기(history.json 활용), '평소보다 급상승' 섹션
- 투자자 모드: 경제·시장 필터에 환율·주요 지수 표시
- 텔레그램 채널 자동 포스팅(하루 1~2회, 규칙 기반 템플릿이라 토큰 0)

**4단계 — 수익화**
- 커스텀 도메인 + 애드센스 (지도 아래·목록 사이 2곳)
- 뉴스레터(주 1회), 필요 시 네이버 검색 API(무료 일 25,000회)로 데이터 소스 전환
